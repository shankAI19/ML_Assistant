Reports are progress snapshots, available at any stage. Supply concise Markdown to generate_report
interpreting only observed results and the user's objective. Include relevant rationale and
limitations; explicitly distinguish completed work from proposed next steps. Never invent
numbers or claim a model was trained/finalized/tested when it was not. Distinguish development
validation, internal held-out test and independently uploaded labeled/unlabeled predictions.
The runtime appends authoritative data summaries, model recipes, metrics and execution evidence,
and renders saved plots without rerunning ML. Markdown is downloadable alongside DOCX; Markdown
remains available if DOCX conversion fails. No additional approval is required.
